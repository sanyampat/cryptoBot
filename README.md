# CryptoBot

CryptoBot is a cryptocurrency trading and analysis project built around machine learning.

The project uses historical crypto market data to train models and provides a web dashboard for looking at predictions, trades, and portfolio performance.

## What it does

* Uses LSTM models for time-series prediction
* Uses LightGBM for market predictions
* Has separate models for stop-loss prediction
* Stores historical cryptocurrency data
* Tracks trades and portfolio performance
* Provides a React dashboard for viewing the data
* Supports multiple USDT trading pairs

## Machine learning

There are a few different models in the project.

### LSTM

LSTM models are used for working with time-series market data and predicting future price movements.

The trained models are stored as `.h5` files.

### LightGBM

LightGBM models are used alongside the LSTM models for prediction based on engineered market features.

These models are stored as `.pkl` files.

### Stop-loss models

There are also separate models for predicting stop-loss levels. The repository contains both the models and their corresponding scalers.

For example:

```text
BTCUSDT_lgb.pkl
BTCUSDT_lstm.h5
BTCUSDT_scaler.pkl
BTCUSDT_stoploss.pkl
BTCUSDT_stoploss_scaler.pkl
```

## Historical data

Historical market data is stored in the `historical_data` directory.

The files are CSVs named after their trading pair:

```text
BTCUSDT.csv
ETHUSDT.csv
SOLUSDT.csv
DOGEUSDT.csv
...
```

This data can be used for training, testing, and experimenting with different trading strategies.

## Frontend

The frontend is built with React and Vite.

It also uses Recharts for displaying charts.

To run the frontend:

```bash
cd client
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

## Backend

The backend code is in the `server` directory.

The exact setup depends on the current backend configuration, so install the required dependencies and run the server from that directory.

## Running the project

Clone the repository:

```bash
git clone https://github.com/sanyampat/cryptoBot.git
cd cryptoBot
```

Install and start the frontend:

```bash
cd client
npm install
npm run dev
```

The backend can be started separately from the `server` directory.
